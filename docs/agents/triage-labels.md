# Triage Labels

The skills use five canonical triage states. These are the default strings; follow any tracker-specific mapping in the contributor-local issue tracker configuration.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an agent |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation |
| `wontfix`                  | `wontfix`            | Will not be actioned |

When a skill mentions a triage state, use the corresponding label string from this table.
